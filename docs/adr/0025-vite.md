# ADR 0025 — Vite como ferramenta de build e servidor de desenvolvimento

**Status:** aceita

## Contexto

O frontend precisa de servidor de desenvolvimento com recarga rápida, build de produção otimizado e acesso à API sem CORS durante o desenvolvimento.

## Decisão

- **Vite** com `@vitejs/plugin-vue` e `@tailwindcss/vite`.
- O servidor de desenvolvimento faz proxy de `/api` pro backend (`BACKEND_URL`, padrão `http://localhost:8080`), igual à produção, onde tudo está na mesma origem.
- O build sai em `frontend/dist`, que a imagem copia pra dentro do backend (ADR 0013).
- O Vitest reaproveita a mesma configuração (ADR 0026).

## Alternativas consideradas

- **Vue CLI (webpack)**: descontinuado em favor do Vite.
- **Nuxt**: SSR e rotas por arquivo, desnecessários pra um sistema interno atrás de login.

## Consequências

- Recarga instantânea no desenvolvimento.
- Uma configuração só pra dev, build e testes.
